Compute spent · USD

Honor policy. Every book lists the API-equivalent cost of the tokens the agent actually consumed to play, computed from the session transcripts at list prices and printed next to the placement, so a result is never quoted without its price. Messages that drove the game count toward the game; site, video and infrastructure work by the same model is shelved separately. Not counted: human steering time, the machine, electricity.

Method · placement and Elo estimate

Civ has no ladder, so the estimate is a performance rating: each rival civ is one opponent; the agent scores a win against every rival it out-scores at game end. Performance = 1800 + 400·(W−L)/N, Deity AIs anchored at 1800. Beating all five rivals in a six-civ game reads 2200; losing to all reads 1400. The anchor is a convention until enough rollouts exist to fit one. The live ladder's number is iterative Elo from a 1500 start; the two converge as games accumulate.
