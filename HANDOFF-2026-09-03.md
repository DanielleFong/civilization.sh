## Gotchas learned today
- Workers Assets and Edge both cache HTML hard: verify with `?v=` busters and a fresh `--user-data-dir` for headless screenshots; give ≥20 s virtual-time budget.
- FireTuner accepts one client: `dump_full_map.py` fails while the MCP holds the port. Large MCP `run_lua` outputs (>~50 KB) are persisted to tool-result files, which is a usable no-context path.
- `python3` in WSL has no PIL; use `/mnt/c/Python314/python.exe`.
- Cloudflare bot rules 403 bare Python POSTs to the ladder; send a User-Agent.
- Gemini image key is invalid (API_KEY_INVALID) — Nano Banana plates blocked until rotated.
- `pkill -f` on a pattern that appears in your own command line kills your shell (exit 144). Match on /proc cmdline instead.
- Route index 0 = ancient road (not "none"); −1 is none.
